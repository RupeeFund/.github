# Code of Conduct

The Rupee Fund Code of Conduct is at [rupeefund.org/code-of-conduct](https://rupeefund.org/code-of-conduct). It applies to every repository, issue, pull request and discussion in the `rupeefund` organisation.

To report a concern, write to [rupeefund@fossunited.org](mailto:rupeefund@fossunited.org).
