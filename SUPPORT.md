# Support

- A bug in a repository: open an issue in that repository.
- A question about the fund, an idea or a contribution: start a [discussion](https://github.com/RupeeFund/RupeeFund/discussions).
- A question about your data: write to [rupeefund@fossunited.org](mailto:rupeefund@fossunited.org).
- To leave the mailing list: write to the same address. [rupeefund.org/privacy](https://rupeefund.org/privacy) tells what data the fund keeps.
- A security problem: read [SECURITY.md](SECURITY.md).
