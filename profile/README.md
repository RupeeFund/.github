# The Rupee Fund

The Rupee Fund is a community initiative from FOSS United, run by volunteers. We support small, independent free and open source software (FOSS) maintainers and builders across India. The [FOSS United Foundation](https://fossunited.org) is the fiscal host.

> The fund does not take payments yet. To hear when it opens, join the list at [rupeefund.org](https://rupeefund.org/subscribe).
